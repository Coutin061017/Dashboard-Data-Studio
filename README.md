# &#x20;Dashboard de Inscrição de Alunos

Painel interativo desenvolvido para facilitar o acompanhamento das inscrições e da conclusão dos cursos de **Educação para o Trânsito**.

O dashboard apresenta indicadores, gráficos e filtros interativos que permitem visualizar os resultados de maneira organizada, auxiliando a gestão na análise das informações e na tomada de decisões.

## &#x20;Objetivo

Centralizar as informações relacionadas aos alunos inscritos nos cursos, permitindo acompanhar a quantidade de participantes, a situação das inscrições e a taxa geral de conclusão.

## &#x20;Indicadores principais

| Indicador         | Resultado |
| ----------------- | --------: |
| Total de alunos   |        48 |
| Alunos concluídos |        31 |
| Alunos pendentes  |        17 |
| Taxa de conclusão |    64,58% |

**Cálculo da taxa de conclusão:**

Taxa = (Alunos concluídos / Total de alunos) × 100

Taxa = (31 / 48) × 100 = **64,58%**

*Os valores correspondem à visualização apresentada e podem variar conforme os dados e os filtros aplicados.*

## &#x20;Funcionalidades do Dashboard

- **Cards de indicadores:** apresentam o total de alunos, concluídos, pendentes e a taxa de conclusão.
- **Gráfico de rosca:** demonstra a distribuição percentual entre alunos concluídos e pendentes.
- **Gráfico de barras:** mostra a quantidade de alunos inscritos em cada curso.
- **Filtros interativos:** permitem selecionar as informações por status, curso e data de inscrição.
- **Tabela detalhada:** apresenta os registros individuais dos alunos, seus respectivos cursos, status e datas de inscrição.

## &#x20;Tecnologias utilizadas

- **Google Data Studio:** desenvolvimento do dashboard, indicadores, gráficos e filtros.
- **Google Sheets:** organização da base de dados utilizada no painel.

## &#x20;Estrutura dos dados

Os principais campos utilizados na análise são:

- **Aluno:** identificação do participante.
- **Curso:** curso no qual o aluno está inscrito.
- **Status:** situação atual, podendo ser Concluído ou Pendente.
- **Data de Inscrição:** data em que a inscrição foi realizada.

## &#x20;Benefícios do projeto

O dashboard transforma os dados de inscrições em informações visuais, permitindo identificar alunos pendentes, acompanhar os resultados dos cursos e analisar os indicadores de desempenho.

Com isso, proporciona maior agilidade no acompanhamento das atividades e contribui para uma gestão mais eficiente e orientada por dados.
